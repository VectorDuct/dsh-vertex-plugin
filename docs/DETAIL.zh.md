# Vertex AI（JSON）

使用自己的 Google Cloud 服务账号，在 DSH 中调用 Gemini。

支持模型目录、流式回复、思考摘要、图片输入和工具调用。每位用户使用自己的项目和凭据。

1. 在「设置 → 凭据 → Vertex AI」导入 JSON。
2. 打开本插件的「vertex-json」组件，设置项目、区域和生成选项，刷新模型目录。
3. 在会话的模型选择器中选择「Vertex AI（JSON）」。

凭据保存在运行 DSH 的电脑上。获取模型目录不代表已验证调用权限；实际对话按你的 Google Cloud 账单计费。本插件为独立软件，不保证账号或模型始终可用。

需要 DSH **0.2.2-rc.2**。本版支持 Gemini 文本和工具模型、图片输入，不含其他发布商或图片／音频生成。
